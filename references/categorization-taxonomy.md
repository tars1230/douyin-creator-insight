## 标签来源

| source | 说明 | 示例 |
|---|---|---|
| `rule` | 规则关键词匹配 | `进外企方法` |
| `hashtag` | 来自视频 hashtag | `#外企` → 进外企方法 |
| `series` | 来自合集名 | `英语学习与提升` → 合集: 英语学习与提升 |
| `llm` | LLM 主题分类 | 由 LLM 补充 |

## LLM 分类提示词

`categorizer.py::build_categorization_prompt` 生成的提示词：

```python
prompt = """你是一个抖音内容分析专家。请基于以下 {N} 个视频的信息，把它们分到合适的类别。

# 任务
1. 输出主分类（每个视频 1 个）：进外企方法 / 外企清单 / 福利揭秘 / 跳槽转行 / 英语学习 / 母婴/育儿 / 其他
2. 提取关键洞察：
   - 博主主要面向谁（年龄/性别/职业）
   - 3 个核心主题
   - 5 条最有价值的视频标题
   - 选题公式（爆款标题的共同特征）

# 输出格式（JSON）
{
  "main_categories": ["..."],
  "audience": "...",
  "core_themes": ["...", "...", "..."],
  "top_5_videos": ["标题1", "标题2", ...],
  "title_formula": "...",
  "insights": "..."
}
"""
```

## 扩展指南

要新增分类：
1. 在 `CATEGORY_KEYWORDS` 字典中添加新类别 + 关键词列表
2. 重跑 `categorize_videos()` 即可

要改 LLM 提示词：
1. 修改 `build_categorization_prompt()` 函数
2. 调用方传更多视频元数据

## 实战经验

- 史蒂文不做牛马账号的分类分布（200 条视频）：
  - 英语学习与提升：42 条（合集）
  - 职业规划与发展：36 条（合集）
  - 认知与成长合集：5 条（合集）
  - 外企清单散装：12+ 条
  - 进外企方法散装：10+ 条
  - 福利揭秘：5+ 条
- 建议给 LLM 提供至少 10 条样本视频做分类
- 主题分类后建议人工复核 TOP 5，确保准确
