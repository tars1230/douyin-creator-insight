# Pre-questions · AskUserQuestion 模板

## 问询原则

自然语言优先。只有用户没有给目标账号、昵称搜索出现多个候选、或用户要求控制规模/成本时，才提问。默认参数不要逐项打断用户。

推荐输入优先级：

1. 抖音主页 URL
2. `sec_uid`
3. 抖音号 / ID
4. 昵称

昵称支持搜索，但同名账号较多；如果置信度不够，需要让用户确认候选。

## 必填信息

### Q1: 用户输入（creator_query）

```
"请提供抖音号 / 昵称 / 主页 URL"
```

接受输入格式：
- 抖音号（纯数字 6-12 位）：如 `<douyin_id>`（如 `12345678`）
- sec_uid（MS4w 开头）：如 `MS4wLjABAAA...`
- 昵称：如 `史蒂文不做牛马`
- 主页 URL：如 `https://www.douyin.com/user/MS4w...`

如果用户已经在一句话里给出上述任意信息，不需要再问 Q1。

## 条件必填（仅当模糊匹配时）

### Q2: 候选博主确认

```
"找到几个相似的博主，请确认哪个是您要的："
```

- option1: <nickname1> <signature1> · 粉丝 X 万
- option2: <nickname2> <signature2> · 粉丝 Y 万
- ...

## 默认参数（通常不问，直接采用）

### Q3: 抓取视频条数

```
"要抓取多少条最新视频？"
- 推荐（200 条）
- 深度（500 条）
- 快速（50 条）
```

默认：200

### Q4: 语音转写条数

```
"要抓取多少条精华视频的语音转写？"
- 5 条（推荐）
- 10 条
- 全部精华（可能耗时）
```

默认：5

### Q5: 转写时长上限（分钟）

```
"转写视频的时长上限？（免费版 actor 限 5 分钟）"
- 5 分钟（推荐，免费）
- 10 分钟（付费）
- 不限（最贵）
```

默认：5

### Q6: 研究目标

```
"主要研究目标？"
- 综合洞察（推荐）
- 选题拆解
- 爆款分析
```

默认：综合洞察

### Q7: 输出格式

```
"输出哪些格式的报告？"
- HTML（可视化）
- Markdown（快读）
- JSON（数据分析）
```

默认：全部

### Q8: 输出目录

```
"报告保存到哪里？"
```

默认：当前工作目录 `./output/`

## 什么时候主动改成小样本

用户出现这些意图时，建议先小样本：

- “先试一下”
- “省额度”
- “先看看能不能跑通”
- “教程演示”

推荐小样本：`max_videos=50`、`transcript_count=1`。如果用户明确说完整分析或未指定规模，则使用默认 `max_videos=200`、`transcript_count=5`。

## 完整调用示例

```python
from AskUserQuestion import ask_user_questions

questions = [
    {
        "key": "creator_query",
        "question": "请提供抖音号 / 昵称 / 主页 URL",
        "required": True,
    },
    {
        "key": "max_videos",
        "question": "要抓取多少条最新视频？",
        "default": 200,
        "options": [50, 100, 200, 500],
    },
    # ...
]

answers = ask_user_questions(questions)
```
